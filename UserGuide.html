Agentic Workspace Console Guide

Standard Operating Procedures & Interface Documentation

If py doesn't work, try python instead. On Mac/Linux run the initialization script directly in your terminal:

python3 plan-console.py
  1. Start the app. A window with two tabs appears: Intake and Sessions.
  2. Repo folder (top bar): click Browse… and choose your project folder — the folder whose code your agent will work on.
    First time experimenting? Create an empty test folder and use that.
  3. Click Init starter repo. This creates inside your repo:
    • PART-00.md — the rulebook every agent session must follow
    • templates/PART-01.md — the blank plan form
    • commands/ — 7 instruction files the console and agent use
    Existing files are never overwritten.
  4. API key (top bar): paste your OpenRouter key, or leave empty for copy-paste mode. It is stored only on your computer, in plan-console.json next to the app.
  5. Model (top bar): click Reload models — the list comes live from OpenRouter, so it always matches what you use in Zoo Code.

    Pick your favorite (free models end in :free). Models you pick are remembered at the top of the list. This model is used only by the console for the intake step — sessions always run in your agent, with whatever model you chose there.

🎉 Done. You never have to do steps 5–8 again (they're remembered automatically).

4. Creating a new plan (from a brainstorm or audit report)

  1. Open the Intake tab.
  2. Paste your brainstorm or audit report into the big text box.
  3. Type: choose brainstorm or audit.
  4. Slug: a short name for the plan, lowercase-with-dashes, e.g. payments-v2 or edge-hardening.
  5. Click Proceed.

What happens next

  • The console saves your pasted text as plans//SOURCE.md (permanent record of what you started from).
  • Then it creates the plan files: a draft plan (PART-01.draft.md), a checklist of facts to verify (RECON-CHECKLIST.md), and questions only you can answer (OPEN-QUESTIONS.md). For audits, also a TRIAGE.md that sorts every finding into fix-now / later / accept.
  • Everything the console did appears in the log at the bottom.

The owner pass (the only manual thinking step)

The log shows you OPEN-QUESTIONS.md. For each question:

  • If you know the answer: open plans//PART-01.draft.md in VS Codium, put the answer in the right section, then DELETE the question line from OPEN-QUESTIONS.md.
  • Owner actions (right-hand panel): commands the agent may never run — needing your passwords, dashboards or owner-only files — are listed from ## Owner actions in OPEN-QUESTIONS.md. Read-only commands (Select-String, Test-Path, Get-Content, git status/diff/log) get a Run (read-only) button: the console runs the command in your repo, shows the output, and — after you confirm — marks the linked §B line VERIFIED and ticks the action done. Anything else: Copy command, run it in your own terminal, then Mark done. Nothing runs or is written without your confirmation; every event is archived to owner-pass.log.

Then handle RECON-CHECKLIST.md: items the agent could already check are ticked [x]. Items left for you: run them, and change [ ] to [x] when done (or delete lines you decide to skip).

Freezing the plan

Click Freeze. It refuses (with a clear message) while questions or unchecked items remain — that's intentional, it's protecting your production cycle.
