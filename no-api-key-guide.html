No-API Workflow

How to Use Plan Console Without an API Key

The API key is optional. Plan Console works seamlessly with your AI coding agent via copy-paste—completely free, with zero model queues.

How It Works

The console and your agent never talk to each other directly. Instead, communication happens securely through clipboard actions and repository files:

Console → Agent : ready-made instructions (copied to clipboard, popup, or saved in plans/<slug>/instructions/) Agent → Console : files generated in your repo (plans/<slug>/...)

The console always checks the files afterward, ensuring half-finished or lazy agent work still gets caught.

Step by Step

  • 1
    Intake
    Paste your brainstorm or audit report into the Intake tab. Pick the type, type a slug, and click Proceed. Copy the instruction from the popup and paste it into your agent with the repo open as the workspace folder. The agent will create the draft plan, open questions, and the recon checklist.
  • 2
    Owner Pass
    Answer the questions in OPEN-QUESTIONS.md (delete each answered line), run any owner-only commands yourself, and tick [x] the finished items in RECON-CHECKLIST.md.
  • 3
    Recon (Optional)
    Click "Run recon" and paste the popup instruction into your agent. It checks your repo locally—instant and free.
  • 4
    Validate
    Click "Validate draft" and paste the instruction. The agent writes the report to plans/<slug>/VALIDATION.md. Click "Show validation report" in the console to read it with a verdict.
  • 5
    Freeze
    Click Freeze. This step is instant and involves no agent. By design, the console will refuse to freeze while questions or checklist items remain unresolved.
  • 6
    Sessions
    Go to the Sessions tab. Enter your slug + session number, click "Copy session instruction", and paste it into your agent to watch it work. Click "Session report" for the verdict before moving to the next session. The console blocks skipping ahead (e.g., session 3 cannot run before 1 and 2 are complete).
  • 7
    Deploy
    The final session is owner-supervised. Click "Plan health" first for the pre-deploy check.
